# Auditor — локальные субтитры EN / RU

**Auditor** превращает речь из системного звука macOS в живые субтитры. Сервер принимает PCM по WebSocket и выполняет обработку на Linux с NVIDIA GPU. Доступны английская и русская транскрипция без перевода, а также EN → RU. Аудио и текст не отправляются в облачные сервисы.

- Модель выбирается по языку: `distil-large-v3` для EN, многоязычная `large-v3-turbo` с фиксированным `language="ru"` для RU.
- HTTP API подготавливает модель до начала записи; после отключения клиента рабочие процессы завершаются, освобождая память моделей и CUDA-контексты.
- Переводчик загружается только для EN → RU и работает независимо от распознавания.
- API состояния показывает модель, токены, серверные задержки, CPU, RAM, GPU и VRAM.
- Один активный аудиосеанс; ограниченные очереди и контроль перегрузки.
- Готовый аудиофайл отправляется отдельным `POST /v1/transcriptions`: сервер выбирает EN/RU модель, возвращает полный текст и освобождает её.
- Новый WebSocket `/v2/live`; старый `/v1/live` совместим с прежним EN → RU клиентом.

**Стек:** Python 3.14, FastAPI, faster-whisper, CTranslate2, OPUS-MT. Аппаратные метрики читаются из Linux `/proc` и `nvidia-smi`; дополнительных Python-зависимостей для них нет.

**Запуск:** установите зависимости через `pip install -e .`, затем `./scripts/run-linux.sh`. Сервер стартует без моделей. Для живого режима клиент вызывает `POST /v1/models/load`, дожидается `ready` через `GET /v1/system`, подключается к `/v2/live` и ждёт WebSocket `ready` перед отправкой аудио. Для готового файла достаточно одного `POST /v1/transcriptions` с языком и бинарным содержимым записи.
