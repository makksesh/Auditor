# Auditor — субтитры и перевод речи в реальном времени

**Auditor** превращает английскую речь из системного звука macOS в живые субтитры с переводом на русский. Сервер принимает аудиопоток по WebSocket, распознаёт речь и отправляет клиенту английский текст и перевод по мере готовности. Обработка выполняется локально: аудио и текст не отправляются в облачный сервис.

### Что здесь сделано

- Потоковая обработка звука с черновыми и финальными субтитрами.
- Независимые очереди распознавания и перевода: медленный перевод не задерживает следующий английский фрагмент.
- Ограничение очередей и контроль перегрузки, чтобы клиент не получал устаревшие субтитры.
- Автоматические тесты протокола и длительного аудиопотока.

**Стек:** Python 3.14, FastAPI, WebSocket, faster-whisper, CTranslate2, OPUS-MT. Сервер рассчитан на Linux с NVIDIA GPU; клиент — на macOS.

**Запуск:** установите зависимости через `pip install -e .`, затем выполните `./scripts/run-linux.sh`. Подробные требования, настройки и адрес подключения — в [инструкции по серверу](docs/server.md); формат клиентских сообщений — в [описании протокола](docs/client_description.md).
